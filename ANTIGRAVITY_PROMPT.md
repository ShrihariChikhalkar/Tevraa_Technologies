# Prompt for Google Antigravity

You are a senior product designer, brand strategist and full-stack frontend engineer. Improve this existing React + Vite company website into a premium, production-quality digital technology agency website.

## Business context
We are a technology company providing:
- Website design and development
- AI / ML engineering, Generative AI, LLM applications, RAG and AI agents
- Android, iOS and cross-platform application development
- Custom software and SaaS product development
- Workflow automation, API integrations and business process digitization
- Data engineering, analytics, cloud deployment and technical consulting
- Technology solutions across healthcare, education, manufacturing, retail, finance, logistics, agriculture and real estate

## Visual direction
- Strict premium black-and-white / grayscale identity. Avoid bright accent colors and gradients.
- Minimal, confident, editorial design with generous whitespace.
- Strong typography, precise grid, thin borders, subtle motion and refined hover states.
- The website should feel like a serious global technology studio, not a generic IT template.
- Keep the design accessible, responsive and fast.
- Use the existing Manrope and DM Mono typography unless there is a compelling design reason to improve it.

## Your tasks
1. Inspect the existing project before changing anything. Keep it as a React + Vite project unless there is a strong technical reason not to.
2. Refine the visual hierarchy, spacing, typography, mobile layout and interactions.
3. Add a high-quality Projects / Case Studies section with realistic clearly-labelled sample projects. Do not invent real clients, awards, metrics or testimonials. Mark all sample content as illustrative placeholders.
4. Add a clear differentiator section explaining how we combine software engineering, AI and business understanding.
5. Improve service descriptions so non-technical business owners understand the outcomes.
6. Add strong calls to action throughout the site.
7. Make navigation, mobile menu, form validation, keyboard focus and reduced-motion behavior work properly.
8. The contact form must have a clear production integration point. Do not pretend a message was sent if no backend exists. Keep a working mailto fallback or add a clearly documented API integration placeholder.
9. Add SEO metadata, semantic HTML, accessible labels and useful page titles.
10. Check the website at mobile, tablet and desktop widths. Fix overflow, broken layouts and console errors.
11. Keep all company name, email, phone, address, social links and project details easy to update from a central configuration file if practical.
12. Do not add unnecessary dependencies or paid services.

## Brand content
Use `YOUR COMPANY` as a temporary placeholder wherever the real company name is unknown. Do not invent a registered company name or contact details. Use `hello@yourcompany.com` only as a clearly marked placeholder.

## Quality bar
The final result should look like a bespoke, premium digital engineering company website. Prioritize clarity, trust, strong visual design, fast loading and real usability over decorative effects.

After implementation:
- Run `npm install` if needed.
- Run `npm run build`.
- Fix all build errors.
- Summarize the files changed and explain exactly how to run the site.


## Motion and animation direction
The starter now includes a CSS motion system. Extend it with restraint and polish:
- Scroll-triggered reveal animations with staggered timing.
- Animated hero entrance, orbiting rings, floating interface elements and subtle grid movement.
- Continuous capability ticker that pauses on hover.
- Refined hover transitions for service cards, industry rows, buttons and links.
- Smooth anchor navigation and subtle section transitions.
- Add small interaction feedback without making the site feel noisy.
- Respect `prefers-reduced-motion` and avoid scroll-jacking, flashing, excessive parallax or animations that hurt readability.
